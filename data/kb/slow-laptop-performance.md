# Slow Laptop Performance

## Quick fixes

1. **Restart** the laptop. Laptops that only sleep for weeks slow down; restart at least
   once a week.
2. Close browser tabs you are not using. Each tab can use hundreds of MB of memory.
3. Open **Task Manager** (Ctrl+Shift+Esc), sort by **CPU** and **Memory**, and close
   applications you do not need.

## Check disk space

1. Open **File Explorer → This PC**. Keep at least **15%** of the C: drive free.
2. Run **Disk Cleanup** (search for it in the Start menu) and tick **Temporary files** and
   **Recycle Bin**.
3. Set OneDrive files to **Free up space** so they stay in the cloud until opened.

## Pending updates

Install Windows updates from **Settings → Windows Update** and restart. Updates that are
downloaded but not installed often cause slowness.

## Startup applications

Open **Task Manager → Startup apps** and disable apps you do not need at startup (for
example personal cloud sync tools or game launchers). Do not disable security software.

## When to ask for help

Contact the Service Desk if:
- The laptop is still slow after all steps above.
- You hear loud fan noise constantly or the laptop gets very hot.
- The laptop is more than 4 years old (it may be due for replacement).
- You see disk or memory errors.
