# Software Installation Requests

Employees do not have administrator rights on company laptops. Software is installed from
the approved catalog or through a request.

## Install approved software (self-service)

- **Windows:** open **Software Center** from the Start menu, find the application, click
  **Install**.
- **macOS:** open **Self Service** from Applications, find the application, click **Install**.

Commonly available: Microsoft 365 apps, Teams, Zoom, Adobe Acrobat Reader, 7-Zip,
Notepad++, Visual Studio Code, Python, Git, Chrome, Firefox, Slack.

## Request software that is not in the catalog

1. Go to the IT portal at `https://it.example.com` → **Request Something** →
   **New Software Request**.
2. Provide the software name, version, vendor website and business justification.
3. Your manager approves the request.
4. Security reviews new software within **5 business days**.
5. Paid software also needs a cost center for the license.

## Install fails in Software Center

1. Restart the laptop and try again (pending Windows updates often block installs).
2. Make sure you have at least 10 GB free disk space.
3. Connect to the office network or VPN; some packages download from internal servers.
4. In Software Center, open the app and check the error code under **Installation status**.

## Browser extensions

Only extensions on the approved list can be installed in Chrome and Edge. Request others
through the same New Software Request form.
